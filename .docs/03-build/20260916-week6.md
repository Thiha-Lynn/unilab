## CR1 — explicit owner request, not an interview finding

Source: owner request on 16 Sep 2026 to convert lecturers' HTML files to readable
PDFs across mobile/desktop/PDF readers, plus deployment and reliability fixes.
This change request is recorded separately from P1–P12 and F1–F15. It is not claimed
as validated research and does not change the interview count.

Acceptance: local HTML selection (20 MB maximum); every static slide included;
original slide layout or A4 portrait reading copy; visible page preview; direct PDF
download; script/network isolation for imported content; clear warning about
external assets, interactive content and image-based text; maximum 150 pages.

Implementation: `src/html-document.js`, `src/tools/html-to-pdf.js`. Original slides
become sharp page images. Browser Print / Save PDF is an alternative for selectable
text. PDF itself needs no HTML browser or JavaScript to view. Dynamic charts need
a self-contained static export first; exact arbitrary-web-app rendering is not promised.

## Definition of Done and review policy

A change needs a source (P#/F# or explicit CR#), passing tests/build, user-visible
limits, relevant output/network checks, reviewed diff, and recorded live revision.
Main protection now enforces the successful `Tests and production build` check,
up-to-date PRs, linear history and resolved conversations, including for admins;
force pushes and deletion are blocked. Use feature branches and PRs; do not force-push main or bypass failed checks. The
Product Owner owns course scope; Tech Lead owns releases; QA owns evidence. A claim
is not Done while its required measurement remains absent.
