## Run each session

1. Confirm consent, distinct person and target-student eligibility. Record prior experience; separate pilot data from the main cohort.
2. Give the scenario, not button instructions. Observe the participant's usual method first, using the same task and comparable input. Start timing when they begin; stop when the saved output is opened and checked. Record baseline tool, device, outcome and interruptions in notes. If the old method fails, record that failure; do not invent a successful baseline time. Only successful, comparable, observed baselines belong in the calculator's `Before_sec` comparison field.
3. Have them perform the same task in UniLab without coaching. Record elapsed seconds even for failed/assisted attempts, errors, hesitation count and output inspection. Mark **Assisted** if any facilitator help was required; it is not an unassisted success. Recalled times must be labelled `recalled` and are excluded from paired comparisons.
4. Repeat for all four tasks. Keep network and device conditions recorded. Doing the old method first may introduce practice effects; disclose this limitation rather than claiming a controlled causal experiment.
5. Let the participant answer all 10 SUS and 11 TAM questions themselves after using the system. Leave unanswered items blank. Ask what worked, where they struggled, and whether they would use it again. Do not suggest scores.
6. Export the session CSV to restricted storage. Verify its participant code and actual date. Keep any permitted photos/videos separately, referenced by code. No email address, private filename or personal document belongs in the public repository.
