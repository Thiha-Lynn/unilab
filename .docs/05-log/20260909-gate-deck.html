Compliance · rule.md rewritten against this product (W2 → LR1–LR8)Zaw Win Htut · 25 s

Compliance is architecture.

LR1No user file content leaves the device; no upload endpoint exists — PDPA minimisation LR2No account, email, name or phone for any tool LR3Network fetches carry program code or model data only, disclosed before they start — 2 of 2 tools verified LR4No "files never touch a server" claim unless the architecture makes it true — it does, so the privacy page reads its numbers from the code LR5Results in memory only, expire unaided, erasable on demand, unreachable once dropped — proven by test LR6Redaction, blurring and EXIF stripping remove content, never cover it — EXIF proven; redaction test still to write (B15) LR7No interview PII into an AI tool or the public repo — role, pain, quote only, kept for all 15 LR8No filename or file content reaches the console in production

A duty you have discharged can fail. A duty you never incurred cannot.

CCA §26 access log, 90 days, a launch blockerWe store nothing for anyone. No server, no session, no IP — there is no event to log.
Consent banner, ad-script gating, DPANo ads, no analytics, no third party collects anything through the page.
ETA §9/26 consent recordsNothing is transmitted, so nothing creates the obligation.

Written conditionally, not deleted: if the system ever stores a file for a user, this duty returns in full. The class draft that assumed a server is preserved verbatim beside the rewrite.
